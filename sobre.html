Como a plataforma funciona

Jogando

Para jogar, basta criar uma conta, escolher um avatar e entrar em uma experiência. Dá para jogar sozinho ou com amigos, no computador, no celular ou no console.

Criando

Para criar, usa-se o Roblox Studio, um programa gratuito. Ele permite montar o cenário com blocos e escrever scripts na linguagem Luau para dar vida ao jogo.

Curiosidades

O Roblox foi lançado em 2006 e, desde então, a maior parte do conteúdo passou a ser feita pelos próprios jogadores.

Você sabia?

Hoje os jogos do Roblox são chamados de experiências, porque nem todos são jogos no sentido tradicional: alguns são lugares para conversar ou assistir a eventos.

Glossário

Avatar
O personagem que representa o jogador dentro das experiências.
Experiência
Nome dado a cada jogo ou mundo publicado na plataforma.
Roblox Studio
Programa gratuito usado para criar e publicar experiências.
Luau
Linguagem de programação usada nos scripts das experiências.
Robux
Moeda virtual da plataforma, usada para comprar itens.
Obby
Tipo de experiência em que o jogador precisa passar por um percurso de obstáculos.
